## 全逻辑复查后的二轮速度优化（1.0.3）

读了 `CodeBuddy CN.app` 内置 git 扩展编译源码确认 API 语义：
`repo.diff(true)` = `git diff --cached`（暂存区），`repo.diff(false)` = `git diff`（工作区）。
本次 4 处优化：
1. `getDiff` 原来「先 diff(true) 空了再 diff(false)」会跑两次 git 子进程 → 按
   `repo.state.indexChanges.length` 只发一次，暂存区为空才回退。
2. `extension.ts` 里 `git.stageAll` 后的固定 `setTimeout(500)` 盲等 → 改为监听
   `repo.onDidChange` 事件驱动等待（2s 兜底），通常几十 ms 完成。
3. `makeHttpRequest` 加 keep-alive Agent（https/http 各一个，模块级共享），
   同一会话第二次起生成省 TLS 握手约 100-300ms。
4. 请求加 30s socket 超时，防止 Ark 卡死时进度通知永久转圈。
另外修正 `autoStage` 代码兜底值 true → false（与 package.json 声明默认一致）。
编译 + 打包通过，1.0.3 vsix 已验证含全部改动（onDidChange/keepAlive 均在包内）。
速度天花板仍是模型本身（mini 关闭思考后约 0.6-1.3s），IDE 侧开销已压到接近下限。
