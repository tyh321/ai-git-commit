- **根因**：用户实际配置为火山方舟 `doubao-seed-2-0-mini-260428`（非 package.json 默认的 deepseek-v3-2）。

  显式 disabled=0.58s/0 reasoning tokens，显式 enabled=2.08s/139 reasoning tokens。
  思考 token 既拖慢响应，又挤占 `max_tokens` 预算（200 太小，中文多行格式会被截断）。

  3. `parseResponse` 旧实现用 `/```[\s\S]*?```/g` 会把模型输出整段删光 → 改为只剥离首尾代码块包裹、保留内容。
- **实测验证**：关闭思考 + max_tokens 500，reasoning_tokens=0、finish_reason=stop、中文 emoji 格式完整输出。
- 已用 npx 缓存的 vsce 重新打包 `ai-git-commit-1.0.0.vsix`（含修复）。

## package 脚本改为自动升版

- `package` 脚本改为：`npm version patch --no-git-tag-version && npm run compile && npx @vscode/vsce package`。
  注意必须加 `--no-git-tag-version`，否则 npm version 会自动 git commit + tag，违反用户"未经确认禁止提交"规则。
- 默认输出 `ai-git-commit-<version>.vsix`，版本每次 +0.0.1（1.0.0 → 1.0.1 → 1.0.2 实测通过）。
- `.vscodeignore` 增加 `.workbuddy/**`：曾把 `.workbuddy/memory/` 工作日志打进 vsix，已修复并验证为 0 文件。
- npx 缓存命中后 `npm run package` 约 12s（首次冷启动约 5 分钟，勿中途杀）。
